# bf-fetch Privacy Policy

bf-fetch is a personal, single-user tool used by its developer only. It is not offered to the public.

What it accesses: when the developer signs in with their own Google account, the tool requests read-only access to Google Drive (the drive.readonly scope) in order to download files from one specific shared folder.

What it stores: the tool keeps an OAuth token on the developer's own computer so it can run without signing in again. No Google user data is sent to any server, sold, shared with third parties, or used for advertising.

Retention and deletion: downloaded files stay on the developer's own computer. Access can be revoked at any time at https://myaccount.google.com/permissions
